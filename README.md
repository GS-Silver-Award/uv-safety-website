# UV Safety Awareness Website

A standalone, responsive website created from the supplied **Sunscreen Safety Silver Award.pdf**.

## Included
- Accessible responsive navigation
- UV safety information sections
- Interactive 8-slide slideshow
- Keyboard, touch, and autoplay controls
- Expandable myth/reminder cards
- Cream/yellow/teal/pink palette inspired by the supplied design
- Decalotype display font and DM Sans body font

## Run it
Open `index.html` in a modern browser. No build step is required.

## Accessibility
- Skip-to-content link
- Semantic headings and landmarks
- ARIA labels and live slide status
- Keyboard controls: Left/Right/Home/End
- Touch swipe support
- Respects `prefers-reduced-motion`

The site does not embed or merely link to the PDF; the content and design are built into the website.
